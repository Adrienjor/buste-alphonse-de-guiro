# Buste Alphonse de Guiro

Démonstrateur de numérisation 3D du projet « Corpus 3D du patrimoine sculpté fribourgeois ».

Les fichiers model-1.bin, model-2.bin, model-3a.bin, model-3b.bin et model-4.bin sont les morceaux du modèle GLB original, réassemblés dans le navigateur sans modification. Les textures sont intégrées.
